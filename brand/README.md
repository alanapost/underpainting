# Brand files

Tools link to these by address, so don't rename or move them.

| File | Use |
| --- | --- |
| `icon-512-light.png`, `icon-512-dark.png` | Square icon: Stripe, Pocket ID logo, Rocket.Chat logo, Tymeslot logo |
| `favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `favicon-180.png` | Browser icons (Pocket ID, Rocket.Chat; 180 is the Apple touch icon) |
| `vikunja-logo-light.png`, `vikunja-logo-dark.png` | Header wordmark (Vikunja, 168x48 slot) |
| `email-wordmark.png` | Email headers (Pocket ID email logo, Rocket.Chat email header, Tymeslot email logo); show at 292px wide |
| `login-background-light.jpg`, `login-background-dark.jpg` | Login screens (Pocket ID, Rocket.Chat), 1920x1080 |

Colors: accent `#7c3f25` (dark mode `#d08a5c`), background `#f2ece1` (`#1e1915`), text `#2a221d` (`#efe6da`). Fonts: Cormorant Garamond 500 for headings, Source Serif 4 for body.
